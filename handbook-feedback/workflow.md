# Handbook Feedback Workflow

## When to write feedback
- You发现某段：不准确 / 讲不清 / 缺案例 / 缺代码 / 结构不顺 / 中英不一致

## Draft format
Use `templates/handbook-feedback-template.md`.

## Submission options (choose one)
1. **GitHub PR / Issue** (preferred if you can)
   - Repo: https://github.com/lxdao-official/aiweb3school
   - Put the exact Handbook link in the description.
2. **Contribution page**
   - https://aiweb3.school/zh/contribution/
3. **Community discussion**
   - Ask in the Telegram group, then turn the conclusion into a PR/issue.

## After submitting
- Add “Submission link” back into the feedback file.
- Optionally reference it in your next daily check-in.

> Reminder: This learning repo is public — do not paste private links or sensitive info.
